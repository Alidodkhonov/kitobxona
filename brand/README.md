# Brand files — Китобхонаи Азим

| Folder | What's inside |
|---|---|
| `logo/` | **Main logo (arch)** in light-mode and dark-mode versions: horizontal, stacked, Tajik and Latin lockups, symbol, header logos, adaptive `favicon.svg`, `favicon.ico`. |
| `full-kit/` | The complete application set (83 files): badges and seal, ex libris and book stamps, website, mobile app icons and splash, social, one-colour versions. |
| `favicons/` | 21 favicon variations (square, circle, arch, symbol only × colourways), each with SVG, ICO and PNG sizes. |
| `animations/` | `bookshelf.mp4` (book pulled from a shelf becomes the logo, 1920×1080) and `arch.mp4` (arch logo reveal, 1080×1080), with the scripts that render them. |
| `design-system/` | Brand rules (`README.md`) and design tokens (`tokens.json`). |
| `fonts/` | Cormorant Garamond 600/700 and Golos Text 500/600 (SIL Open Font License), used to outline lettering. |
| `previews/` | Overview boards. |
| `brandkit.py`, `f2kit.py`, `f2build.py` | Generators: lettering outlines, the К mark, and the full kit build. |
